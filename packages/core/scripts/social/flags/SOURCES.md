# Flags for the airing time card

Thirty country flags from Twemoji 15.1.0 (https://github.com/jdecked/twemoji),
the SVG files under `assets/svg/`, unchanged. Graphics licence: CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/), copyright Twitter, Inc and
other contributors.

Each file is named by the country's two-letter code (`us.svg`, `gb.svg`).
zones.mjs lists the countries; a country without a file here is drawn
without a flag.
